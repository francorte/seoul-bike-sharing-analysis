# Datos

Este proyecto utiliza **Seoul Bike Sharing Demand**, disponible en el UCI Machine Learning Repository:

- Ficha: https://archive.ics.uci.edu/dataset/560/seoul%2Bbike%2Bsharing%2Bdemand
- DOI: https://doi.org/10.24432/C5F62R
- Licencia: CC BY 4.0

El notebook descarga los datos mediante `ucimlrepo` usando el identificador 560. No se incluye inicialmente una copia del archivo para evitar duplicación y conservar la trazabilidad hacia la fuente.

Si en una fase posterior se guarda una copia local, deberá mantenerse sin modificar en `data/raw/`; los datos transformados irán en `data/processed/` y se documentará cada cambio.
